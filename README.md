# AI 天津站站长吴敬中飞行检查

> 每日一款 AI 产品 · 站长亲自下场实测 · 八段式飞检档案

借《潜伏》吴敬中"飞行检查"梗，每天调研一款 AI 产品（AI 原生 / AI 增强），输出八段式深度档案：

1. 飞检通告
2. 产品身份核查
3. 实战测试（3 个真实 case，截图+计时+步骤）
4. 核心 AI 能力拆解
5. 定价与商业模式
6. 竞品比对
7. 站长锐评
8. 飞检结论（绿/黄/红 + 给我们的产品启示）

## Stack

- Next.js 14 (App Router) + Tailwind + MDX
- 静态导出（GitHub Pages 部署）
- 老纸黄 #f4ecd8 / 印章红 #c0392b / 鎏金 #b89764 设计 token

## Dev

```bash
npm install
npm run dev   # http://localhost:3007
```

## 三条红线

- **不编造** — 实战必须真截图、真任务
- **不抄文案** — 报告自己写，不复制官网
- **不留情面** — 是好就是好，是坑就是坑
